# 一蔬一饭新手教程

一蔬一饭是一款用来记录每日饮食、图片、贴纸和吃饭心情的轻量应用。第一次使用不需要注册账号，所有内容都可以只保存在本机；需要跨设备时，再创建账号并开启云同步即可。

## 一、先认识底栏

默认底栏有三个入口：

1. **今日**：记录当天或其他日期吃了什么。
2. **迹**：查看每天形成的小本本，并进入日历。
3. **我**：调整主题、个性化、个人信息、数据安全与更新。

开启实验性功能中的营养师后，再次点击底栏“今日”可以在今日和营养师之间切换。关闭营养师后，重复点击今日不会执行任何操作。

进入“我”下面的主题、个性化、个人信息等任意子页面后，再点一次底栏“我”会直接回到“我”首页；已经停留在“我”首页时重复点击不会跳动。

## 二、记录早餐、午餐和晚餐

1. 进入“今日”。
2. 点击早餐、午餐或晚餐卡片中的文字区域。
3. 输入这餐吃了什么。
4. 点击空白处即可收起输入法，内容会自动保存在本机。

右上角日期可以左右滑动切换前一天或后一天，也可以点击日期打开日期选择器。切换日期时只更新日期和餐次内容，不会整页闪烁。

## 三、标记没有吃饭

早餐、午餐和晚餐没有吃时，可以在餐卡上向左滑动，再点击“没有吃饭”标记。标记后，该餐不会出现在日历详情和吃饭本子里；取消标记后可以继续输入。

下午茶和夜宵使用开心、伤心两个心情标记，不使用“没有吃饭”的逻辑。

## 四、下午茶和夜宵

长期使用：进入“我 > 个性化 > 今日 > 餐次管理”，开启下午茶或夜宵。

临时使用：如果设置里没有长期开启，可以在今日页右滑午餐或晚餐，先显示“添加下午茶”或“添加夜宵”按钮，点击按钮后才会加入当天。临时餐次也可以通过右滑删除。

下午茶始终排在午餐和晚餐之间，夜宵排在晚餐之后。

## 五、添加图片或贴纸

1. 点击今日页右下角图片按钮。
2. 三餐会同时、平滑地收缩为餐次标签。
3. 点击餐次卡片主体，从相册选择图片或贴纸。
4. 点击餐次右侧浅色相机图标，可以直接打开相机拍照并添加到该餐。
5. 选择或拍摄完成回到应用后，餐卡会平滑恢复正常状态。

拍照时应用会暂存所选餐次和照片地址；即使相机占用较多内存导致应用页面被系统重建，点“完成”返回后，照片仍会自动加入刚才选择的早餐、午餐、下午茶、晚餐或夜宵。

如果不想继续添加，再点一次右下角按钮即可退出。快速连续点击也不会重复触发动画。

## 六、整理、删除和叠放媒体

长按图片或贴纸会进入整理状态：

1. 拖动可调整顺序。
2. 点击角落删除按钮可移入回收站。
3. 开启叠放后，把一张拖到另一张上可以形成一组。
4. 点击带“×n”的叠放组可以展开，再点展开后的收缩按钮可恢复。

图片或贴纸上滑可以折叠，下滑可以展开。折叠状态会被记住，切换页面后不会自动展开。

## 七、贴纸栏

点击今日页左上角“今日”两个字进入贴纸栏。这里只汇总已添加的贴纸；如果开启图片合集，也会显示普通图片。

贴纸栏支持按天、周、月分组，并可调整每行数量。叠放组与今日页使用同一套原地展开和收缩逻辑。

## 八、足迹页面

点底栏“迹”进入足迹。每个有记录的日期都会变成一本小本本。

1. 点击小本本打开当天的吃饭本子。
2. 只有点击左上角“足迹”两个字才会进入日历，顶栏其他空白处不会跳转。
3. 长按小本本可以填写各餐热量和消费。
4. 手动填写的热量优先于 AI 估算。

在“我 > 个性化 > 全局 > 界面布局 > 足迹”里，可以选择平滑或展开布局、每行本数、年月分组、热量和消费显示，以及本子之间的间距。封面样式单独放在“个性化 > 足迹 > 记录本封面”，可以直接看预览后选择。

开启“显示日期”后，月份会按记录顺序分组；年份只在 1 月与上一年 12 月的跨年边界显示，并使用较轻的灰色文字，避免每组都重复出现年份。

## 九、日历与就餐方式

日历支持左右滑动切换月份，也可以在下方当天记录区域左右滑动切换前一天和后一天。

长按某个日期，可按早餐、午餐、晚餐以及已启用的其他餐次，标记食堂、线下餐厅、外卖或自己做。标签会显示在下方对应餐次右侧。

## 十、吃饭本子

打开小本本后，一蔬一饭会把当天内容整理成笔记纸张：日期、实际吃过的餐次、时间、图片、贴纸、热量等都会按设置排版。

1. 左右滑动可切换相邻日期。
2. 每张纸保持相同高度。
3. 内容过长时，在纸张内部上下滑动查看，不会把某一天撑得特别长。
4. 右上角分享按钮可生成分享图片。

“我 > 个性化 > 足迹 > 笔记页面”中可以调整衔接动画、翻页音效、纸张样式、笔记字体、记录排版、贴纸和图片摆放。

## 十一、分享吃饭本子

分享界面有两种：

1. **全屏界面**：保留吃饭本子标题、纸张和背景。
2. **纸张界面**：导出内容只有纸张本身。

两种界面都会使用“一蔬一饭”水印。水印字体会跟随笔记字体，分享背景只在导出的图片中生效，不会改变应用主页面主题。

## 十二、笔记字体与云端字体

为了缩小安装包，除系统默认字体外，所有笔记字体都改为云端按需下载。带“未下载”的字体不会占用初始安装包空间：

1. 点击字体预览。
2. 选择下载。
3. 等待进度条到 100%。
4. 下载完成后会自动应用。

字体文件保存在应用本机数据中，不属于账号云同步内容。正常覆盖更新不会删除已经下载的字体，也不会重复下载；清除应用数据、卸载应用或更换设备后需要重新下载。

在“我 > 数据 > 关于该软件 > 字体来源”可以查看每款字体的 GitHub 开源项目链接与来源说明。

主题中的“全局字体跟随笔记字体”开启后，除固定顶栏和底栏外，大部分界面文字都会使用当前笔记字体。

## 十三、营养师与 AI

先进入“我 > 个性化 > 其他 > 实验性功能”，配置大模型 API 并通过检测，再开启营养师、自动分析、读取记录、聊天记忆或食物识别。

营养师会结合当天和近期记录给出简短饮食建议。点击右上角头像可填写身高、体重、性别、餐饮习惯、就餐方式和平均消费，并查看 BMI 表与常见食物热量参考。

API Key、接口地址和模型选择只保存在本机，**不会上传到一蔬一饭云端**。常见食物热量是日常估算值，不替代营养师或医生建议。

## 十四、主题与半透明效果

“我 > 主题”中可以选择清新绿色、柠檬黄色、番茄红、湖水蓝或深夜灰，还可以控制：

1. 头像背景半透明。
2. 底栏半透明。
3. 顶栏透明。
4. 全局字体跟随笔记字体。
5. 夜间模式。

夜间模式默认关闭，因此手机系统开启深色模式时，应用仍保持原主题。只有主动打开夜间模式，应用才跟随系统变暗。

## 十五、提示词和震动

“个性化 > 今日 > 提示词管理”可以修改今日页说明、各餐占位文字和没有吃饭提示。震动页面可以分别控制底栏、日历、滑动、编辑等反馈，并选择轻、中、强三档。

## 十六、创建账号和云同步

不登录也能完整使用本地功能。第一次保存昵称时，可以按提示创建唯一 ID；设置密码后，可在另一台设备通过 ID 或昵称加密码登录。

“我 > 数据 > 数据与安全 > 同步数据”提供：

1. 同步本地新增数据到云端。
2. 从云端同步数据到本地。
3. 自动同步。

云同步包含头像、昵称、个性签名、餐饮资料、三餐记录、日历、本子、图片贴纸和 AI 聊天记录，但不包含模型 API 配置。同步前请确认当前账号正确，重要数据建议同时保留本地备份。

## 十七、备份、恢复与回收站

数据与安全中可以导出本地备份、恢复备份、清理数据和打开回收站。删除的图片与贴纸会先进入回收站并保留一段时间，可恢复或彻底删除。

注销云账号会清空该 ID 的云端资料并回收 ID，但不会主动删除本机饮食记录。退出登录后，应用继续作为本地记录本使用。

## 十八、检测更新和查看教程

进入“我 > 数据 > 关于该软件”：

1. **检测更新**：联网获取最新版并打开浏览器下载。
2. **更新日志**：查看最近版本变化。
3. **联系作者**：反馈问题与建议。

更新日志右上角的“教程”会打开本文件。安装新版通常可以直接覆盖旧版，正常情况下不会清空本地记录；为了稳妥，重大更新前仍建议先做本地备份。

## 十九、常见问题

**图片按钮点了没反应**：先检查相册权限，再退出添加模式重新进入。

**字体显示“未下载”**：确认网络可用后重新点击该字体，等待进度完成。

**换设备后没有数据**：先确认登录的是同一 ID，再到同步数据页面执行“同步云端数据到本地”。

**AI 无法分析**：检查 API 是否有效、模型是否已选择，并确认相关实验性开关已开启。

**界面设置混乱**：个性化页面底部可以恢复默认设置。该操作只恢复布局和外观，不会删除饮食记录。

不需要一次把所有功能都设置好。先从今天的一餐开始，慢慢把日子收进小本本里就好。
