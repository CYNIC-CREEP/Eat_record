# 一蔬一饭新手教程

一蔬一饭是一款用来记录每日饮食、餐图和营养估算的轻量应用。第一次使用不需要注册账号，所有内容都可以只保存在本机；需要跨设备时，再创建账号并开启云同步即可。

## 0.6.0 正式版当前操作

没有美食时，餐纸中央显示“点击下方星标可以添加美食喔”。图案和空白区域不再添加图片，请使用下方星标；手写笔入口不变。原图在后台加载，成功后才切换图片与计数，失败会保留当前图片。

餐次记录框中的短文字上下居中，保持原有左右对齐；空白处仍可直接输入，多行内容可滚动查看。图片尚未切换完成时离开应用，返回后继续从当前显示的图片切换。

夜间模式同时切换应用的基础主题与纸面配色，顶栏和页面使用一致的纸色；退出弹窗、切页和重新启动后仍保持所选明暗模式。字体列表会适应内容及窗口高度。

首次使用可配置自己的 HTTPS 视觉 API 来识别菜名和估算营养，也可稍后设置，先使用手写记录和本地抠图。API 配置位于“我 > 智能助手 > 调用 API”；配置后在“餐图识别”中开启自动识别，并明确同意向所配置服务商发送餐图。服务商可能收费，重量、油盐和隐藏食材不是照片实测，请核对。抠图仍在手机本机完成，无需 API Key。旧记录及已有估算继续可读，并保留原有来源，不会因升级改写成 API 结果。

点击周历或月历日期时，餐纸和日期标记会连续切换；快速改选会从当前画面接续，仍不能进入未来。日期选中框和跨周日期跟随美食卡片的同一滑动进度。快速模式兼容回退保留关闭思考参数，但服务商网络、排队和手机本地算力仍会影响耗时。

今日、迹、我可以通过底栏或页面外层左右拖动切换。切换中途可继续点击或反向拖动。点击记录本封面会沿书脊掀开并衔接实际记录页；点击关闭或系统返回时会合上封面并缩回书架。开本中途返回可反向关闭，切换底栏可打断动画；内部翻页方式仍由记录本设置控制。今日餐纸内左右滑动是查看前后日期，不会进入未来；日期区域继续保留周／月日历手势。下方星标添加图片，手写笔直接记录文字，两种入口都可选夜宵；餐纸“…”也可管理夜宵。

餐纸上的手写文字可长按选中，右上角删除按钮仅删除文字，原有餐图、营养和手工热量保留。管理餐次中的空白区域可直接输入，不再打开第二个文本编辑框；提示使用你配置的文案，不会当作餐食保存。点击完成、返回或添加图片前会保存已输入的文字，原有餐图与营养保留。只有点击食物图片实际轮廓才打开该食物的营养详情，名称和留白不触发。详情首屏到膳食纤维、钠和份量，继续上滑可看小贴士、修改与更多操作；“识别信息”仅重新估算菜名／营养，可能有API费用，“重新抠图”只做本地图片处理。

主页面支持短甩切换，旧式横向书架在滑到边界后也可切到相邻主页面。营养师和设置等下级页面使用约 480ms 的整页平移，文字不交叉叠加，纸面边缘会随页面自然移出屏幕；返回方向与进入对应。照片导入会保留更清晰的细节，完整模式继续使用抗混叠和保守主体精修，改善部分托盘/衣物残留；已经保存的旧低清来源需要重新选择原图，重抠旧图不能恢复丢失细节。低内存回退及其他未覆盖照片仍可能需要手动修边。

吃饭记录本标题不再附加表情，翻页纸背沿用当前纸样与主题颜色、保留圆角。下文按当前餐纸界面介绍操作，旧记录继续兼容。

## 一、先认识底栏

默认底栏有三个入口：

1. **今日**：记录当天或其他日期吃了什么。
2. **迹**：查看每天形成的小本本，右上角“收藏”可直接查看已收藏的记录。
3. **我**：配置智能助手，调整个性化、记录本、提醒、个人信息、数据安全与更新。

“我”页的“偏好设置”依次是“个性化”“智能助手”“其他设置”。营养师在“智能助手”中配置；开启后，在今日页再次点击底栏“今日”即可进入分析与问答，返回时回到今日页。关闭营养师后，重复点击今日不会执行任何操作。

进入设置子页面后，可用左上角返回按钮或系统返回逐级返回；底栏用于切换主页面。已经停留在“我”首页时重复点击不会跳动。

## 二、记录餐食文字

1. 进入“今日”，先在上方周历或展开后的月历选择日期。
2. 点击下方手写笔，选择早餐、午餐、晚餐或夜宵。
3. 填写餐食名称，点击“保存”。文字会显示在当天餐纸上。

也可以点击餐纸日期旁的“…”进入“管理今日记录”，选择对应餐次后直接在空白区域输入。此处点击“完成”、返回或转去添加图片前会保存文字；不必再打开第二个编辑框。清空文字会保留该餐的图片、识别信息和手工热量。

在餐纸内左右滑动可以查看前后日期，上方日期也会跟随变化；点击周历或月历日期同样会连续切换，不能进入未来。

## 三、编辑和删除文字

点按已显示的餐食文字可以继续编辑。长按文字会显示居中的选中背景和右上角删除按钮，确认后只删除这段餐次文字，不会同时删除餐图、营养信息或手工热量。文字没有图片的旋转操作。

## 四、夜宵和历史餐次

添加图片和手写笔都提供夜宵选项，不需要先在设置中长期开启。餐纸“…”中的“管理今日记录”也可以编辑夜宵。

此前保存的下午茶、夜宵及其他旧记录仍可读取，按当天实际数据展示；当前餐纸不再使用旧版餐卡的左右滑动添加和心情标记操作。

## 五、添加餐图

1. 点击今日页下方星标按钮，选择早餐、午餐、晚餐或夜宵。
2. 在应用相机中拍摄，或从相册选择原图。
3. 等待本地抠图；如已配置并启用餐图识别，再通过自己的 API 处理菜名和营养。
4. 核对草稿中的图片与信息，明确点击“确定”后才加入日记。

退出或取消草稿不会自动把新图片加入当天，也不会覆盖已有记录。相机或后台处理返回时，应用会保留所选日期和餐次；请仍核对草稿后再确认。

新导入会保留更清晰的细节。旧记录若保存的是低清来源，重新抠图不能补回已丢失的细节，需要重新选择原图。

## 六、查看、旋转和删除餐图

点击食物图片的实际轮廓可查看该食物的营养详情，图片外的留白和名称不会触发详情。长按图片可显示旋转和删除控制；删除需确认，支持的已保存媒体可在回收站恢复。

营养详情中的“更多操作”提供“手动修整贴纸”“重新抠图”和“识别信息”等操作。“重新抠图”只重新处理本地图片；“识别信息”用于重新估算菜名和营养，使用自己的API时可能产生费用。旋转只改变展示方向，不会重编码原图或改变营养数据。

## 七、美食栏

点击今日页左上角“一蔬一饭”进入“美食栏”，这里汇总已保存的餐食图片。右上角“周报”是另一入口，用于查看饮食周报。

美食栏支持按天、周、月分组，并可调整每行数量。点击图片可查看原图，长按可旋转或删除；返回今日时沿用对应的柔和过渡。

## 八、足迹页面

点底栏“迹”进入足迹。每个有记录的日期都会变成一本小本本。

1. 点击小本本打开当天的吃饭本子。
2. 点击顶栏“收藏”查看收藏记录，返回时回到迹页；从收藏打开记录本，关闭后仍回到收藏列表。
3. 长按小本本可以填写各餐热量和消费。
4. 手动填写的热量优先于 AI 估算。

在“我 > 其他设置 > 记录本 > 书架布局”中，可以选择“网格书架”或“横向书架”；网格书架还可设置每行本数、本子间距和日期显示。封面和纸张样式也在统一的“记录本”页，不必再找单独的封面页面。

开启“显示日期”后，会按月份分组，在跨年位置显示年份，方便回看较早记录。

## 九、日历与就餐方式

日历支持左右滑动切换月份，也可以在下方当天记录区域左右滑动切换前一天和后一天。

长按某个日期，可按早餐、午餐、晚餐以及已启用的其他餐次，标记食堂、线下餐厅、外卖或自己做。标签会显示在下方对应餐次右侧。

## 十、吃饭记录本

打开小本本后，一蔬一饭会把当天内容整理成笔记纸张：日期、实际吃过的餐次、时间、图片、贴纸、热量等都会按设置排版。

1. 左右滑动可切换相邻日期；正文不被横向压扁，未翻完可拖回。
2. 每张纸保持相同高度。
3. 内容过长时，在纸张内部上下滑动查看，不会把某一天撑得特别长。
4. 右上角分享按钮可生成分享图片。

“我 > 其他设置 > 记录本”统一分为书架、封面与纸张、阅读、阅读内容和分享。这里可以设置书架排列、封面、纸张、记录本图片边框、翻页及音效、记录方式、图片摆放和分享界面；书架子页返回记录本，记录本返回其他设置。

翻页可选滑动或仿真翻页；拖动跟手，未翻完可反向拖回，取消不会换日期。照片和抠图统一显示，“记录本图片摆放”控制自然斜放或整齐摆放。“记录本图片边框”只影响本子里的小图；首页食物的轮廓边框位于“我 > 个性化 > 食物贴纸轮廓”。字体只在“个性化 > 个性字体”选择。

阅读页名称为“吃饭记录本”，设置入口简写为“记录本”。新用户及恢复默认使用柠檬黄色主题、网格书架，已有明确选择保留。识别星标和手写笔均可选择夜宵，记录前显示“夜”；手写例子显示在输入框下方，输入框提示会按餐次与实际缺席记录随机轮换。夜宵有独立文案，连续真实夜宵记录超过三天才轻提醒，提示不会保存为食物文字。

餐食详情的“更多操作”中，“重新抠图”只做本地图片处理，保留营养；“识别信息”复用现有抠图，并在可能调用收费API前确认。手动修整时单指擦除/恢复、双指缩放和平移，画笔屏幕粗细不随缩放变化。原图和营养不会因为查看、缩放或取消而改变。

## 十一、分享吃饭记录本

分享界面有两种：

1. **全屏界面**：保留吃饭本子标题、纸张和背景。
2. **纸张界面**：导出内容只有纸张本身。

两种界面都会使用“一蔬一饭”水印。水印字体会跟随笔记字体，分享背景只在导出的图片中生效，不会改变应用主页面主题。

## 十二、个性字体与云端字体

默认小赖手写已内置，无需下载；其余个性字体按需下载。应用会自动登录专用的只读分发账号，无需输入你的个人账号。带“未下载”的字体不会占用初始安装包空间：

1. 点击字体预览。
2. 选择下载。
3. 等待进度条到 100%。
4. 下载完成后会自动应用。

字体文件保存在应用本机数据中，不属于账号云同步内容。正常覆盖更新不会删除已经下载的字体，也不会重复下载；清除应用数据、卸载应用或更换设备后需要重新下载。

在“我 > 数据 > 关于该软件 > 字体来源”可以查看每款字体的 GitHub 开源项目链接与来源说明。

在“个性化 > 个性字体”选择后，应用正文、顶栏、底栏和本子统一使用该字体；其他设置不再提供重复字体入口。默认项为内置的小赖手写。

## 十三、营养师与 AI

先进入“我 > 智能助手”。首项“调用 API”填写服务商提供的 HTTPS Chat Completions 地址、密钥和模型；检测模型列表不等于已经实测图片能力，未知别名不会仅凭名字被拒绝。

API Key 输入默认隐藏。已经保存 Key 时，“调用 API”弹窗的密钥输入框下方会显示“删除已保存的 Key”；点击会清除本机保存的 Key，并关闭依赖它的 API 授权，不删除已经保存的吃饭记录、餐图和估算。需要重新使用时，请再次配置并授权。不要将密钥发给他人或放进截图中。

模型列表会分开显示服务商的正式名称与实际调用 ID。例如官方名称 DeepSeek-V4.1-Flash 对应 API ID `deepseek-flash`；不要将展示名称自行拼成新的调用 ID。旧配置缺少名称时，重新点“检测模型”刷新列表并保存即可，密钥不需要发给他人。

DeepSeek 官方严格输出选项使用兼容的 JSON Output，应用仍校验完整营养结果。通用 HTTP 参数错误不等于模型不支持图片；请按提示区分模型 ID、图片格式、权限或接口配置。旧失败草稿可按需选择“识别信息”，本地抠图另有“重新抠图”；不会自动确认加入今日。

“餐图识别”管理自动识别菜名和营养，以及识别已保存食物图片。“高级设置”默认折叠，点击后可调整“严格结构化输出”的 JSON Schema 兼容选项，收起不改变已经保存的选择。菜名和营养估算仅使用你自己配置的 HTTPS 视觉 API，开启前需要同意发送餐图；批量识别会确认可能的 API 费用，已有有效结果和用户修正不覆盖。本地抠图始终无需联网或密钥。

“营养师”设置管理营养师、自动分析、AI读取记录和开启记忆。开启后，在今日页再次点击底栏“今日”即可进入分析与问答；它使用已保存的记录，不自动附带原照片，与餐图识别开关独立。每日热量目标请在首页营养总览设置。

营养师会结合当天和近期记录给出简短饮食建议。点击右上角头像可填写身高、体重、性别、餐饮习惯、就餐方式和平均消费，并查看 BMI 表与常见食物热量参考。

API Key、接口地址、模型选择、云会话和上传授权只保留在本机，使用独立存储并排除本地导出、项目云同步和系统备份。旧版本已导出的文件不会自动改写，请妥善保管；导入旧备份不会覆盖本机凭据或带回旧上传授权。常见食物热量是日常估算值，不替代营养师或医生建议。

## 十四、主题与夜间模式

“我 > 个性化”中可以选择柠檬黄色、清新绿色、番茄红、湖水蓝或深夜灰，还可以控制字体大小、个性字体、食物贴纸轮廓和整体界面疏密。“界面疏密”调整全局间距，与“记录本 > 书架布局”的排列方式是两回事。

查看原图的背景在“我 > 其他设置 > 照片查看 > 原图背景”中设置，不影响原始图片，也不改变记录本图片边框或食物贴纸轮廓。

显示中的夜间模式开关直接切换应用明暗，开启立即变暗、关闭立即恢复浅色，不要求手机同时开启系统深色模式。升级时先保留此前的实际外观，手动切换后以本机选择为准。旧玻璃效果及新旧界面切换入口已移除。

首页识别按钮旁的手写笔可以选择早餐、午餐、晚餐或夜宵，直接填写餐食名称。此入口不上传图片，也不会自动估算营养；收起的日历只显示本周日期，下拉展开后再显示年月。

## 十五、未用餐文案和震动

“我 > 其他设置 > 未用餐文案”可以修改未用餐时显示在记录本中的文字；这些不是发给模型的 AI 提示词。震动页面只保留底栏和图片/贴纸编辑反馈，并选择轻、中、强三档；日历和滑动页面不再震动。

## 十六、创建账号和云同步

不登录也能完整使用本地功能。第一次保存昵称时，可以按提示创建唯一 ID；设置密码后，可在另一台设备通过 ID 或昵称加密码登录。

“我 > 数据 > 数据与安全 > 同步数据”提供：

1. 同步本地新增数据到云端。
2. 从云端同步数据到本地。
3. 自动同步。

云同步包含头像、昵称、个性签名、餐饮资料、三餐记录、日历、本子、图片贴纸和 AI 聊天记录，但不包含模型 API 配置。同步前请确认当前账号正确，重要数据建议同时保留本地备份。

## 十七、备份、恢复与回收站

数据与安全中可以导出本地备份、恢复备份、清理数据和打开回收站。删除的图片与贴纸会先进入回收站并保留一段时间，可恢复或彻底删除。

备份流式写入，恢复先检查文件与可用空间、暂存图片，再提交记录；校验失败保留当前数据，途中失败回滚，未完成的恢复会在再次启动时优先恢复旧状态。“删除数据”在底部谨慎操作区，仍需二次确认。

注销云账号会清空该 ID 的云端资料并回收 ID，但不会主动删除本机饮食记录。退出登录后，应用继续作为本地记录本使用。

## 十八、检测更新和查看教程

进入“我 > 数据 > 关于该软件”：

1. **检测更新**：联网获取最新版并打开浏览器下载。
2. **更新日志**：查看最近版本变化。
3. **联系作者**：反馈问题与建议。

更新日志右上角的“教程”会打开随当前安装包提供的本地教程，无需联网下载。安装新版通常可以直接覆盖旧版，正常情况下不会清空本地记录；为了稳妥，重大更新前仍建议先做本地备份。

## 十九、常见问题

**添加图片没有打开**：确认已选择餐次，再检查相机或相册权限；返回今日后重新点击星标按钮。

**字体显示“未下载”**：确认网络可用后重新点击该字体，等待进度完成。

**换设备后没有数据**：先确认登录的是同一 ID，再到同步数据页面执行“同步云端数据到本地”。

**AI 无法分析**：检查 API 是否有效、模型是否已选择，并确认对应的餐图识别或营养师功能已开启且取得授权。

**界面设置混乱**：进入“我 > 其他设置 > 恢复出厂 > 恢复出厂设置”。确认后只恢复个性化布局、主题、字体、分享样式等界面设置，不会删除饮食记录、图片、贴纸、头像、昵称或 API 配置。

不需要一次把所有功能都设置好。先从今天的一餐开始，慢慢把日子收进小本本里就好。
