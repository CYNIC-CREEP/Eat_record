# 一蔬一饭

一个轻量的原生 Android 一日三餐记录 App。项目不依赖 Gradle 或第三方库，使用 Android SDK 自带工具直接构建，目标是保持 APK 很小。

## 功能

- 今日：记录当天早餐、午餐、晚餐，支持文字输入，长按输入框可插入 emoji。
- 迹：每天自动生成一个日期本子，打开后用时间线查看当天吃了什么。
- 日子：月历视图，长按日期可添加 emoji 标注当天心情。
- 我：设置昵称、本地头像、全局字体、布局、装饰风格、偏好，并可跳转 QQ 联系作者 `3207770874`。

## 构建

需要本机已安装 Android SDK、JDK，并可使用 `javac`、`keytool`、`jar`。

```powershell
.\build.ps1
```

生成文件：

```text
dist\EatRecord-debug.apk
```

## 说明

当前版本为轻量原生实现，数据保存在本机应用私有存储中，不需要网络。
