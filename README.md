# 一蔬一饭

一蔬一饭是一款轻量、原生的 Android 饮食记录应用。它把每天的文字、图片和贴纸整理成一本可以翻阅的吃饭本子，并提供日历足迹、收藏记录、营养师分析和可选云同步。

## 主要功能

- 今日记录：早餐、午餐、晚餐以及可选的下午茶、夜宵，支持文字、图片、贴纸、缺席与心情标记。
- 图片与贴纸：相册、相机上传，长按后可删除、拖动、叠放和向左旋转 90°。
- 足迹本子：按日期生成记录本，支持多种封面、纸张、字体、翻页方式和分享水印。
- 日历与收藏：查看每日餐次、就餐方式和历史记录，收藏重要的一天并切换列表或展开布局。
- 营养师：在用户自行配置兼容接口后，根据个人信息、历史聊天和饮食记录提供分析。
- 个性化：主题、日夜模式、底栏与顶栏效果、布局、震动和云端按需字体。
- 数据安全：本地备份与恢复、回收站，以及登录后的手动或自动云同步；API Key 仅保存在本机。

## 构建

需要 JDK 17 和 Android SDK。项目不依赖 Gradle，使用 Android SDK 自带工具直接构建：

```powershell
.\build.ps1 -NoUpload
```

生成的 APK 位于 `dist/`。

## 隐私说明

不登录时，记录只保存在应用私有目录。启用云同步后，个人资料和记录会同步到用户配置的服务端；实验性功能中的大模型 API Key 不会上传。
