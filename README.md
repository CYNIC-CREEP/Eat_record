# 一蔬一饭

一蔬一饭是一款轻量、原生的 Android 饮食记录应用。它把每天的文字、图片和贴纸整理成一本可以翻阅的吃饭本子，并提供日历足迹、收藏记录、营养师分析和可选云同步。

## 主要功能

- 今日记录：在统一餐纸中按日期浏览餐食，支持三餐及可选加餐的文字、图片、食物贴纸与手动热量；兼容旧餐次记录。
- 图片与贴纸：拍照或相册导入后本地抠图，明确确认才加入日记；支持旋转、删除、修边、重抠图与识别信息。
- 足迹本子：按日期生成记录本，支持多种封面、纸张、字体、翻页方式和分享水印。
- 日历与收藏：查看每日餐次、就餐方式和历史记录，收藏重要的一天并切换列表或展开布局。
- 营养师：在用户自行配置兼容接口后，根据个人信息、历史聊天和饮食记录提供分析。
- 个性化：主题、日夜模式、字体大小、记录本布局、震动和按需字体。
- 数据安全：本地流式备份、校验与事务恢复、回收站，以及登录后的手动或自动云同步；API与云会话配置独立保存在本机。

## 构建

需要 JDK 17 和 Android SDK。项目不依赖 Gradle，使用 Android SDK 自带工具直接构建：

```powershell
.\build.ps1 -NoUpload
```

生成的 APK 位于 `dist/`。

## 隐私说明

不登录时，记录只保存在应用私有目录。启用云同步后，个人资料和记录会同步到用户配置的服务端；实验性功能中的大模型 API Key 不会上传。

beta.34起，新导出与云同步均剥离API配置、云会话和上传授权；这些字段迁到排除系统备份／设备迁移的独立preferences，备份前执行清理屏障。旧版本已导出的文件不会自动改写，导入时不接受其凭据和授权。此分存不是新增应用层静态加密；实际系统备份传输仍需专门验收。
